# 🐾 4 Paws - Animal Hospital Management System

## 📖 Overview
**4 Paws** is a full-stack **Animal Hospital Management System** designed to digitalize and simplify daily operations in animal healthcare.  
It enables staff and pet owners to manage appointments, medical records, pharmacy items, pet shop transactions, and more — all through a secure, role-based web platform.

This project was developed as our **3rd Year Group Project** at the **University of Ruhuna**, Faculty of Technology. 🎓

---

## 🚀 Key Features
### 🧩 User & Role Management
- Role-based access control (Admin, Doctor, Doctor Assistant, Pharmacist, Pet Owner)
- User registration, profile management, and password updates
- JWT-based authentication & secure login system

### 🐕 Pet & Medical Records
- Manage pet profiles and owners
- Add and view medical history, prescriptions, and treatment details
- Appointment scheduling and real-time tracking

### 💊 Pharmacy Management
- Manage medicines with stock quantity, expiry date, and price
- Add, update, or remove items
- Track transactions 

### 🛍️ Pet Shop Management
- Manage product inventory, pricing, and categories
- Handle sales and customer orders
- Generate and scan QR codes for product tracking

### 📅 Appointments
- View, create, and update appointments for pets
- Real-time status updates (Pending, Completed, Cancelled)

### 🧠 Other Features
- Admin dashboard with analytics and user overview
- Secure JWT-based route protection
- RESTful APIs and modular architecture
- Responsive UI with Tailwind CSS
